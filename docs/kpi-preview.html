events_per_pixel is the key lever

Tuning a single parameter — events_per_pixel from 0.01 → 0.10 — reduced total runtime by 7× and raised mAP@0.5 by 30 percentage points. Sparser frames force the model to generalise; denser frames bury the signal.

LSTM warm-up artefacts (first ~250 frames)

The E2VID LSTM requires ~20 s to warm up from a cold start. Bounding boxes in the first 250 frames are geometrically correct but the reconstruction appears visually empty to a human observer.

Event camera settling noise

All sequences show elevated noise in the first few seconds, likely due to the event camera settling after power-on. This produces spurious detections at sequence start and is a sensor characteristic, not a model artefact.
